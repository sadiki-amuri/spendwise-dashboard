##SpendWise Interactive Theme Dashboard Shell

An addition to our front-end architecture introducing accessible fluid card micro-animations alongside user-preference dark theme transitions.

## Features Implemented
 
-Accessible Component Micro-interactions:Cards monitor continuous hover and focused actions using an optimized `200ms` spatial shift (`translateY`) and shadow offset framework.
-  Auto Dark Theme Scope: Integrates user media controls (`@media (prefers-color-scheme: dark)`) to automatically adjust backgrounds and texts without using redundant tracking layout code.
-  Structural CSS Grid & Flexbox: Retains macro column grid splits alongside micro layout spacing configurations.
